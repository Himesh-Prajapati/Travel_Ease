# ✈️ Travel Ease

A modern full-stack travel booking and trip management platform designed to help users discover destinations, plan journeys, and manage travel experiences seamlessly.

## 🌐 Live Demo

https://travel-ease-delta.vercel.app/

---

## 📖 Overview

Travel Ease is a travel management application that provides a smooth and user-friendly experience for exploring destinations, organizing trips, and managing travel-related information. The platform focuses on delivering a clean interface, responsive design, and efficient travel planning workflows inspired by modern travel platforms. Travel services commonly include flights, hotels, holiday packages, and trip planning experiences.

## ⚡ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/travel-ease.git
cd travel-ease
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd ../server
npm install
```

---

## 🔐 Environment Variables

Create a `.env` file inside the server folder:

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

CLIENT_URL=http://localhost:5173
```

---

## ▶️ Run Locally

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend
```bash
cd client
npm run dev
```
